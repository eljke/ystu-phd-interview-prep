# Исследование и проектные решения

## Учебные механики

1. **Активное воспроизведение до просмотра подсказки.** Karpicke и Roediger показали, что повторное извлечение материала может давать более устойчивое запоминание, чем одно повторное чтение: https://doi.org/10.1126/science.1152408
2. **Мягкое распределённое повторение.** Метаанализ Cepeda et al. рассматривает 839 оценок из 317 экспериментов и показывает зависимость полезного интервала от требуемого срока удержания: https://pubmed.ncbi.nlm.nih.gov/16719566/
3. **Сначала индивидуальный ответ, затем обсуждение.** В Peer Instruction обсуждение концептуального ответа используется после личного выбора; результаты десятилетнего применения описаны Crouch и Mazur: https://mazur.harvard.edu/publications/peer-instruction-ten-years-experience-and-results

Отсюда следуют режимы продукта: скрытый каркас ответа, тесты, устная попытка, оценка партнёра и рекомендации без штрафа за пропуски.

## Технические решения

- Vite документирует настройку `base` и GitHub Actions для публикации в подпапке GitHub Pages: https://vite.dev/guide/static-deploy.html
- HashRouter хранит маршрут в hash-части URL, которая не передаётся статическому серверу: https://reactrouter.com/api/declarative-routers/HashRouter
- Dexie предоставляет типизированную оболочку IndexedDB и React-интеграцию: https://dexie.org/docs/Tutorial/React
- vite-plugin-pwa генерирует service worker на основе Workbox и поддерживает контролируемый запрос обновления: https://github.com/vite-pwa/vite-plugin-pwa

## Ограничение содержания

Пул экзаменационных тем определяется только приложением № 1 к программе ЯГТУ. Внешние источники используются для объяснений внутри темы, а не для создания новых экзаменационных вопросов.
