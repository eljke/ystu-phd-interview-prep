# Подготовка к собеседованию ЯГТУ 1.2.2

Offline-first приложение для двух человек, готовящихся к устному вступительному испытанию в аспирантуру ЯГТУ по специальности **1.2.2 «Математическое моделирование, численные методы и комплексы программ»**.

## Что реализовано

- все 43 пункта программы: 16 тем математического моделирования, 10 тем численных методов и 17 тем комплексов программ;
- свободный каталог: темы доступны сразу, без блокировок, обязательной дневной нормы и штрафов за перерывы;
- ответы двух уровней — каркас на 30–60 секунд и раскрытие на 1–2 минуты;
- ключевые понятия, формулы, короткие примеры, типичные ошибки и 2–4 источника на тему;
- пять типов мини-тестов: один ответ, несколько ответов, сопоставление, порядок и заполнение пропуска;
- устная тренировка с настраиваемыми этапами подготовки и ответа;
- парные сессии: все темы, слабые темы отвечающего, слабые темы пары и пробное собеседование;
- самооценка, оценка партнёра по критериям и автоматическая смена ролей;
- два локальных профиля, личная готовность и готовность пары по более слабому участнику;
- мягкая очередь повторения, которую можно игнорировать или откладывать;
- экспорт, проверка, предварительный просмотр и объединение резервных копий JSON;
- IndexedDB через Dexie, PWA и работа после первой успешной загрузки;
- подготовленный интерфейс репозитория для будущего Supabase-адаптера;
- автоматическая публикация на GitHub Pages через GitHub Actions.

## Запуск в IntelliJ IDEA

Требуется Node.js 22.

1. Откройте каталог проекта через **File → Open**.
2. В **Settings → Languages & Frameworks → Node.js** выберите Node.js 22.
3. Откройте встроенный Terminal и выполните:

```bash
npm install
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`.

## Основные команды

```bash
npm run dev            # локальная разработка
npm run verify         # typecheck, lint, аудит контента, тесты и production build
npm run test:run       # модульные тесты однократно
npm run content:audit  # проверка полноты и согласованности 43 тем
npm run build          # production-сборка в dist
npm run preview        # локальный просмотр production-сборки
npm run format         # форматирование исходников
```

Для E2E-тестов:

```bash
npx playwright install chromium
npm run e2e
```

## GitHub Pages

1. Создайте GitHub-репозиторий и отправьте проект в ветку `main`.
2. Откройте **Settings → Pages → Build and deployment → Source**.
3. Выберите **GitHub Actions**.
4. Workflow `.github/workflows/deploy-pages.yml` вычислит `base` из имени репозитория, выполнит проверки и опубликует `dist`.

Для ручного значения `base`:

```bash
VITE_BASE=/имя-репозитория/ npm run build
```

## Хранение и перенос данных

Прогресс находится в IndexedDB текущего браузера и не отправляется на сервер. Для переноса используется экран «Резервная копия»: приложение проверяет версию, контрольную сумму, ссылки между сущностями и показывает результат объединения до сохранения.

При первом переносе на второе устройство используйте те же имена участников: при объединении приложение сопоставляет профили по идентификатору или имени и не допускает появления третьего профиля. Если состав участников отличается, остаётся только явно выбранная полная замена.

Учебные экраны работают через интерфейс `StudyRepository`, а локальная реализация находится в `DexieStudyRepository`. Это позволяет позднее добавить облачный репозиторий, не меняя логику тестов, устных и парных сессий.
